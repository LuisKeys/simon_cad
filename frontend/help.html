Simon CAD Help

Simon CAD is an agent-first CAD environment for robotics, mechatronics and 3D-printable parts. You describe what you want in plain language (and by clicking things in the 3D view); the agent turns it into validated, undoable, replayable CAD operations. This page documents everything the app can do today, with prompts you can copy and paste.

How to use this page. Every PROMPT block has a Copy button. Paste it into the Conversation box on the right of the app and press Enter. Blocks marked TOOL ARGUMENTS are exact JSON for the command palette (Ctrl+K). Press / to search this page.

1 · Describe

“Create a 100 × 60 × 4 mm plate.” Natural language, any phrasing.

2 · Review

The agent proposes a ChangeSet. Preview it as a ghost in the viewport.

3 · Commit

Commit it, or reject it. Everything is undoable and checkpointed.

4 · Refine

Select a face, edit a parameter, ask for changes. Export STEP / STL when done.

Quick start

Start the app, which opens in your browser:

make ui # or ./out/simoncad --project my_part.scadproj

The agent needs an LLM provider configured in .env (see Configuration). Without a key, everything except free-form prompts still works: palette tools, parameter edits, undo/redo, timeline, materials, export.

Your first five minutes

  1. Type in the Conversation box:
    Create a 100 x 60 x 4 mm plate called base_plate.
  2. The agent replies with a ChangeSet card. Click Preview to see the ghost, then Commit (at Review level).
  3. Click the top face of the plate in the viewport. A chip appears above the prompt. Then:
    Add four M3 clearance holes, 8 mm in from each corner.
  4. Make it look right:
    Make the plate brushed aluminum.
  5. Round it and export:
    Fillet the four vertical corner edges with a 5 mm radius, then export it as STL to out/base_plate.stl.
  6. Press Ctrl+S to save the project.

Core concepts

ChangeSets: nothing happens behind your back

Every change, from you, from the palette or from the agent, is a ChangeSet: a small list of validated commands that is previewed, then committed as a unit. There is no hidden path that edits the model. That is why every edit can be undone, replayed and compared.

Interaction level

LevelBehaviour
Review (default)Every ChangeSet is shown as a proposal; you Preview, then Commit or Reject. Agent edits that were committed during a turn appear as a draft you can keep or discard.
AutoLow-risk single-feature ChangeSets commit immediately. Multi-feature changes and checkpoint restores are always previewed.

Parametric, with expressions

Features store parameters (dx, radius, depth…). Change one and everything downstream rebuilds. A parameter can also be driven by an expression referencing other features, e.g. plate.dz * 3. Allowed: numbers, + - * / ^, parentheses, pi, sin cos tan sqrt abs min max round.

Selectors

Clicks become topology-backed selectors the agent understands:

SelectorMeaning
face(feature=F, side=+Z)Planar face facing +Z at the extreme of the part
face(feature=F, side=+Z, at=6)Planar face facing +Z in the plane z=6 (e.g. a pocket floor)
face(feature=F, index=N)Any face (cylinder walls…) by kernel index
edge(feature=F, index=N), vertex(feature=F, index=N)Edge / vertex by index
body(feature=F)The whole body

index= selectors are only valid for the model they were picked on, so the selection is cleared whenever the model changes.

Coordinates and units

Millimetres and degrees. X right, Y into the screen, Z up. Planes: XY (normal +Z; u=X, v=Y), YZ (normal +X; u=Y, v=Z), XZ (normal +Y; u=Z, v=X).

How to write good prompts

  • State dimensions in mm and say what the part is for. “A 20 mm standoff for an M3 screw” beats “a post”.
  • Name things. “called base_plate” gives you a stable id to refer to later (“fillet base_plate”).
  • Select instead of describing. Click the face, then say “add a hole here”. The agent sees the face’s type, normal, centroid, bbox and area.
  • One idea per prompt when you want precise review. Chain several in one prompt when you trust the result.
  • Ask before changing. “What are the features and volume of the model?” is a query: it changes nothing.
  • Correct freely. “Make the holes 3.4 instead”, “undo that”, “go back to before the fillet”.
  • Thinking mode (checkbox) enables extended reasoning for hard requests; turn it off for instant answers to simple ones.
Intent verbs. The palette offers openers for engineering intent: Mount, Attach, Connect, Reinforce, Fit, Clear, Hollow, Support, Align, Center, Protect, Lighten, Adapt, Enclose. They drop a sentence starter in the prompt box for you to complete, e.g. Reinforce ….

Intent-style prompts

Mount a NEMA 17 stepper (42.3 mm square, 31 mm hole spacing, 22 mm center boss) on the front of this plate.
Hollow the box leaving 2 mm walls and an open top.
Lighten this bracket: add three 8 mm round pockets through the web, evenly spaced.
Reinforce the inside corner with a 6 mm fillet.
Center the boss on the top face of the plate.

Primitives

Box, cylinder, sphere, cone / frustum, torus. Position with x,y,z (box: minimum corner; others: center or base center). Cylinders, cones and tori take an axis (x, y or z).

Create a 100 x 60 x 4 mm plate.
Add a 12 mm diameter, 20 mm tall cylinder standing on the plate at x=50, y=30.
Create a sphere of radius 15 mm at the origin.
Make a cone with a 20 mm base radius, 8 mm top radius and 30 mm height.
Create a torus with a 25 mm major radius and a 3 mm tube radius, lying flat.
Add a horizontal cylinder along the X axis, radius 5, length 80, centered at y=30 z=20.
Create a 40 x 40 x 40 mm cube named block.

Sketches, extrude and cut

For anything that is not a primitive, sketch a 2D profile and extrude it. Profiles: rectangle, circle, slot, polygon (and lines/arcs in full sketches). Add material or cut (requires a target; through cuts everything).

Quick profile + extrude

Extrude a 40 x 20 mm rectangle 8 mm tall on the XY plane.
Make an L-shaped bracket: polygon with points (0,0) (60,0) (60,5) (5,5) (5,40) (0,40), extruded 25 mm.
Cut a 30 mm long, 6 mm wide slot through the plate, from (20,30) to (50,30).
Cut a 20 mm diameter circular pocket 3 mm deep into the top of base_plate, centered on the plate.
Extrude a circle of radius 10 symmetrically, 20 mm total.

Full sketches (reusable, editable)

Create a sketch on the XY plane with a 60 x 30 rectangle at the origin and a 6 mm diameter circle centered at (30,15), then extrude both regions 5 mm.
Sketch on the selected face: a 10 mm circle at the center, then cut it 4 mm into the material.
Create a sketch on the XZ plane offset 10 mm with a slot from (0,0) to (30,0) width 8, and extrude it 15 mm.
Sketches drawn on a face start at the face centroid, with u along its longest straight edge. A cut from a sketch on a face goes into the material.

Holes

Simple, counterbore and countersink holes on axis-aligned planar faces. The face defaults to the top (+Z) of the target. Omit depth for a through hole. Typical sizes: M3 clearance 3.2–3.4 mm, M4 4.3–4.5, M5 5.3–5.5.

Drill an 8 mm hole through the center of the plate.
Add four M3 holes (3.4 mm) at (10,10), (90,10), (10,50) and (90,50).
Add a 5 mm hole, 6 mm deep, into the selected face.
Add an M4 counterbore hole: 4.5 mm through, 8 mm counterbore diameter, 4 mm counterbore depth, at the center.
Add a countersunk M3 hole: 3.4 mm through, 6.5 mm countersink diameter, 90 degrees, at (20,20).
Drill a 6 mm hole in the -X side face of the block.
Add 4 M3 holes here, 8 mm in from each corner of this face. (with a face selected)
Limit. Holes currently start only from axis-aligned planar faces.

Fillets and chamfers

By default they treat every edge of the body. Select specific edges first (set the pick filter to Edge, shift-click several) and they only touch those.

Fillet all edges of base_plate with a 2 mm radius.
Chamfer the selected edges 1 mm.
Round only the four vertical corner edges of the plate with a 6 mm radius.
Add a 0.5 mm chamfer to the outer edges after cutting the pocket.
Tip: fillet/chamfer last. Changing earlier features later rebuilds them, but a radius that no longer fits will fail with an actionable message.

Booleans, patterns, mirror, transform

Boolean (union · subtract · intersect)

Both inputs are consumed. Create the tool body first, position it, then combine.

Union the boss cylinder into base_plate.
Create a 30 x 30 x 10 box at (35,15,0) and subtract it from the plate to make a pocket.
Intersect the sphere with the cube to get a rounded cube.

Linear and circular patterns

Patterns repeat a hole or extrude-cut feature. count is the total number of instances (2–500).

Repeat the hole 5 times along X with 15 mm spacing.
Make a 4 x 3 grid of the hole: first 4 along X every 20 mm, then 3 along Y every 20 mm.
Pattern the hole 6 times around the Z axis through the center of the plate (50,30).
Make a half-circle arc of 5 holes: circular pattern, 180 degrees total, around z through (0,0).

Mirror

Mirror the arm across the YZ plane and merge with the original.
Mirror the bracket across the XZ plane shifted 20 mm along +Y.

Move and rotate

Move the cylinder 25 mm along +X and 10 mm up.
Rotate the arm 90 degrees about the Z axis through the origin, then move it 50 mm in X.
Tilt the plate 30 degrees about the X axis.

Scale, dimensions, duplicate, align and groups

Scale

Uniform with a factor, or per axis. The fixed point is the body’s centre by default; base keeps the bottom on the print bed.

Make the bracket 50% bigger, keeping it on the bed.
Scale the lid to 80% along X only.
Scale this part by 2 about the origin.

Dimensions

Select an object to see its width, depth and height in the viewport (along the object’s own axes, so a rotated part keeps its width), in every view of the Quad layout. Click a number to type a new size: Enter applies it, Esc cancels, Ctrl+Z undoes it. The same values are editable in the Selection panel’s Dimensions section. Only the dimension you change changes, unless Lock proportions is on; the anchor (center or object origin) is the point that stays put. It is a scale of the body, not a parametric edit: a cylinder made wider becomes elliptical and holes scale with the part.

Increase the width of this part to 150 mm without changing its height or depth.
Incrementá el ancho de esta pieza a 150 mm sin modificar su altura ni profundidad.
Make the lid 60 mm tall keeping its proportions.
Resize the bracket to 80 × 40 × 12 mm about its origin.
What are the dimensions of the selected part?

Duplicate

A copy is linked: it follows later parameter edits of its source (change the source’s size and the copy changes too). It keeps the source’s colour, material and group. Ctrl+D duplicates the selection.

Duplicate the standoff 20 mm along +X.
Make a copy of these two parts 50 mm up.

Align

Moves bodies so their bounding boxes line up (each moved body gets a transform feature, all in one undoable change). With several bodies the first selected stays put; with one body, alignment is to the world origin.

Align the selected parts on their centres along X and Y.
Put the boss on the floor (minimum Z = 0).
Line up the tops of these three blocks with the base plate.

Groups

Groups organize the design tree; they never merge geometry (use a boolean union for that). Grouping is presentation-only: it commits immediately, never rebuilds geometry, and is undoable. A feature built on a grouped body joins its group. Ctrl+G groups the selection, Ctrl+Shift+G ungroups it.

Group the base plate and the bosses as “Chassis”.
Rename the Chassis group to “Frame”.
Ungroup Frame.

Components: reusable projects

A component is a reusable project. There is no second kind of thing to learn: you save a project as reusable, and other projects can place instances of it. An instance is a reference, not a copy — four wheels on a car are four references to one wheel project. Edit the wheel once and every car that uses it can pick the change up.

Open the Components panel from the header to browse, search, insert, open, rename and delete them.

Create one from what you already modelled

Select the objects and use Component in the action bar, Create component… in the right-click menu, or just ask. The geometry moves into a new reusable project and is replaced in place by a single instance.

Turn the selected brake assembly into a reusable component called “Brake”.
Make this wheel a component named Wheel, tagged chassis.

The selection has to be self-contained: nothing outside it may depend on it, and it may not depend on anything outside. If it is not, the refusal names the features that cross the line so you can add them to the selection or detach them first.

Place instances

Insert from the Components panel, or ask for them. Each instance has its own placement — position, rotation and scale — which stays editable in the design tree like any other parameter.

Use the Wheel component from my library and place four instances on the car.
Insert the Engine component at x=0, y=120, z=40.
Move Wheel FL 10 mm along X.

Edit a component

Open component opens its project normally — the same tree, the same tools, the same agent. There is no separate component editor. Save it, reopen the project that uses it, and the instances are flagged out of date: the design tree badge turns amber and the Components panel offers to update them.

Update all component instances to the latest version.

Updating is an ordinary ChangeSet, so you can review it, see it in the history, and undo it. Undoing restores the old reference, which simply puts the instances back to “out of date” — it does not bring back the old geometry, because only the latest saved version of a component is kept.

Components inside components

A component may contain other components, to any depth — a wheel assembly made of a tire, a rim (itself containing a hub) and a brake assembly. There is no nesting limit. What is refused is a circular reference: if A uses B and B uses C, then C cannot use A. The refusal spells out the chain it would have closed.

Detach

Detach component replaces an instance with its own local copy of the geometry, as ordinary features in your tree. After detaching, changes to the component no longer reach it. Detaching is refused while other features are built on the instance — remove or re-point them first.

Detach Wheel FL so I can modify just that one.

Publish the project you are in

The button at the bottom of the Components panel marks the current project as reusable, so other projects can instantiate it. Save afterwards to publish it. Use it when a project is the part, rather than containing it.

Face extrude, inset and offset

Select a face (pick filter Face or Auto), then use Extrude, Inset or Offset in the action bar, or ask the agent. Each is a parametric feature: its distance stays editable in the design tree.

OperationWhat it does
Extrude (push/pull)Sweeps the exact outline of a planar face along its normal. Positive adds material outward; negative cuts into the body.
InsetShrinks a planar face’s outline by a distance from its edges. With a depth the inset region becomes a pad (+) or a pocket with a rim (−). Without depth it only splits the face, so the inner face can be selected and extruded on its own.
OffsetMoves any face along its normal; the faces around it stretch or shrink to follow. On a cylinder the radius changes. “Outward” means out of the material, so on a hole wall a positive offset makes the hole smaller.
Pull the selected face out 5 mm.
Push this face in 2 mm.
Inset the top face 3 mm and sink it 4 mm to make a tray.
Inset this face 2 mm and raise it 1 mm as a pad.
Make the selected hole 0.2 mm bigger for clearance. (face_offset −0.1 on the hole wall)
Faces picked by index belong to the model they were picked on: select again after other changes. Several faces of one body are edited one at a time.

Parameters, expressions and feature management

Change a value

Make the plate 5 mm thick instead of 4.
Change the boss radius to 8.

You can also expand a node in the Design tree and type the new number: each edit is a modify_parameter ChangeSet.

Link parameters with expressions

Make the boss height always three times the plate thickness.
Drive the standoff height with the expression plate.dz * 3 + 2.
Clear the expression on the boss height and keep its current value.

Rename, suppress, remove

Rename box_1 to “Base plate”.
Suppress the fillet so I can see the part without it, then unsuppress it.
Remove the second hole feature.
Suppressing is non-destructive. Removing fails if other features depend on the feature; the message lists them.

Inspect and measure

Queries never change the model.

Summarize the model: features, bounding boxes and volumes.
What is the distance between the top face of the plate and the top of the boss?
How far apart are the two selected faces?
What checkpoints do I have?
Which feature owns the selected face, and what depends on it?

In the viewport, the Measure action gives a two-point measurement overlay: click two surface points.

Delete

Delete / Backspace (outside text fields) or Delete in the right-click menu deletes the selection as one ChangeSet; Ctrl+Z undoes it. The app only asks two questions, both before anything changes: “a face/edge/vertex can’t be deleted — delete its owning feature instead?” and “these features depend on it — delete them too?”

Delete this. (with an object selected)
Remove the selected part.
Delete the boss and everything that depends on it.
Delete these objects. (with several selected)

Colour, opacity and visibility

Presentation only: geometry, volume and exports are not changed. Without a feature name they apply to the current selection. In the UI: expand a feature in the tree → Appearance (colour picker, hex or rgb(r,g,b) field, opacity slider, visibility checkbox, Reset). The eye icon on a tree row toggles visibility.

Make the bracket red.
Color the plate #1f6feb.
Make the cover semi-transparent.
Set opacity to 30% on the selected bodies.
Hide the reference servo.
Show everything again and reset the colors.
What colors and opacities have I overridden?
Hidden bodies are not pickable and are excluded from Fit, but they still exist and are exported.

Materials

A material or colour stays with the part as you keep working on it: a hole, fillet, scale, move, face edit or boolean carries the look of the body it modifies.

A visual PBR library (30 materials, below). Choose via prompt, via Choose… in the Appearance group (search, category chips, sphere thumbnails), by dragging a thumbnail onto an object or tree row (dropping on a selected object applies to the whole selection), or right-click → Material… / recent materials / Remove material. Color and opacity are overrides on top of the material. Everything is a ChangeSet with undo, and never rebuilds geometry.

Make the bracket brushed aluminum.
Use black ABS for the enclosure and clear glass for the window.
Make the base look like carbon fiber, but keep my blue color.
I want something metallic for this part. What are my options?
Ambiguous wording (“metallic”, “black plastic”) makes the agent search the library and show you the candidates instead of guessing.
Show me all the wood materials.
Make the wood texture twice as large on the selected panel.
Remove the material from the plate.
What are the properties of titanium?

Image to CAD

Turn a sketch, scan, technical drawing or photo of paper / whiteboard into editable parametric geometry (sketch + extrude/cut features, no image object remains).

  1. Attach the image: 📎 Attach, Create from Image, drop it on the window, or paste from the clipboard (PNG, JPEG, WebP; large images are downscaled to ≤ 2048 px).
  2. The agent’s interpretation opens in the Image interpretation panel: your image with an SVG overlay (solid = outline, dashed = hole, boxes = dimensions it read), confidence bands (≥ 85 % / ≥ 60 % / uncertain) and the open questions, usually just overall width and thickness.
  3. Edit detected values, tick confirm on low-confidence ones, choose boolean intent for overlapping shapes, and a placement: plane XY/XZ/YZ or the selected planar face. Optionally keep the source image in the project.
  4. Create & preview shows the ordinary ghost preview with Commit / Reject. Correct with the agent… sends the image back to the composer.
Create editable geometry from this drawing. The overall width is 80 mm and it is 6 mm thick.
Make this sketch into a bracket plate. The scale: the 400 px wide edge is 80 mm.
That small circle in the corner is a hole, not a boss.
The left edge is vertical; the dimension reads 12, not 17.
Put this profile on the selected face and extrude it 4 mm.
Only create the 2D sketch from the image, I’ll extrude it later.
Honest by design. The agent never infers real size from pixels. Missing dimensions are listed and must come from you.

Specification documents

Attach (or drop) also accepts text documents (.txt .md .json .csv .yaml .xml…; ≤ 200 KB each, 400 KB total), e.g. the spec of a part or a datasheet. They show as 📄 chips and are sent with every request as short-term memory until you press Clear or open/create a project. They are never saved with the project.

Read the attached specification and create the part it describes.
According to the attached datasheet, add the mounting holes for the servo.
Does the current model meet every dimension in the attached spec? List the differences.

Command palette

Press Ctrl/⌘+K. Type to filter:

  • Intent verbs: sentence starters for the agent.
  • Every registered tool: pick one and an argument skeleton opens (with the current selection prefilled). Edit the JSON and Run tool. This is the direct path that bypasses the LLM, handy for exact edits.
  • Commands: undo / redo, save, export, playback, new.
  • Ask the agent: whatever you typed, sent as a prompt.
{ "dx": 100, "dy": 60, "dz": 4 }
Paste into the create_box form. See the tool reference for every tool.

Tool reference

All tools the agent, the palette and the CLI can call. Edit tools produce a ChangeSet; query tools return data and never change the model. Unknown arguments are rejected, and errors are written to be actionable. Click a tool for its arguments and an example. The full schemas are in docs/tools.md.

Common optional arguments on feature-creating tools: id (lowercase letters, digits, underscores), name (human-readable) and intent (why, in natural language, stored on the node).

Token consumption and cost

Every request to the model is metered. Under each answer you get the tokens that turn consumed (input and output), and above the message box a running total for the session — hover it for the split per model and for the last turn. Clearing the conversation does not reset the meter.

Cost estimation is opt-in: fill Token Prices under Settings → Primary Model (and Fallback Model) with what each model costs per million input and output tokens (the figures from your provider's pricing page) and pick a currency. From then on each turn and the session also show an estimated cost. Leave the fields empty and only tokens are reported — Simon never guesses a price. If a turn used a model you have not priced (for example a vision model that read your image), its tokens are still counted and the estimate is marked partial rather than silently understated. Local (Ollama) models have no prices: their tokens are shown as local and never counted as spend.

Primary and fallback models

The Primary Model answers every request it can. The Fallback Model, OpenAI or Anthropic, takes over only what the primary cannot do: an image or PDF a local model cannot read, or a request whose primary model stopped responding. The header of the Simon Agent panel shows the model at work (for example Ollama · qwen3, or OpenAI · gpt-x (Fallback) — hover it for the reason), and every fallback is noted in the conversation. Turn the fallback off and such requests are refused with an explanation instead. When the primary model is local, Simon asks before it first sends anything to the cloud; tick Remember my choice to keep the answer, and change it later in Settings → Fallback Model → Remote data.

Part of what you send is usually served from the provider’s cache and billed cheaper: the system prompt and the tool list repeat on every step, which is exactly what caches well. The tooltip shows how much was cached, and Cached input price makes the estimate reflect it. Leave that field empty and cached tokens are charged at the full input price — the estimate errs high rather than flattering itself.

Simon also keeps the request small: the image and reference-modeling tools are only sent when there is an image in the project, which cuts about a third of the tokens off a plain modeling turn. Attach an image and they come back automatically.

Components are found next to the open project (its folder, its parent, their projects_output/) and in the configured library — never relative to the directory you started the program from, so the same project always rebuilds to the same geometry.

Launch options: --project file.scadproj opens or creates a project; --no-browser does not open a tab; --recording file.json runs a scripted agent without an API key.

Limits and troubleshooting

Known limits

  • Holes start only from axis-aligned planar faces.
  • index= selectors are valid only for the model they were picked on.
  • Patterns repeat holes and cut features only.
  • Scale, align and face edits apply to visible bodies (not to features a later feature consumes). Face extrude and inset need planar faces; non-uniform scaling turns cylinders into free-form surfaces.
  • A component instance is one body with one appearance: per-feature colours and materials inside a component are not kept when it is instantiated.
  • Only the latest saved version of a component is kept. Instances record which version they are on and report when they are behind, but cannot be pinned back to an older one yet.
  • Creating a component writes its project to disk outside the undoable change. Undoing leaves that project in the library; delete it from the Components panel if you do not want it.
  • A component can only be made from a self-contained selection, and an instance can only be detached while nothing is built on it.
  • No robotics catalog or macros yet; intent verbs are natural-language openers.
  • Edits are refused while the agent is working on a turn (the UI keeps updating).
